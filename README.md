# LinkLite URL Shortener

![LinkLite Landing Page](landing-page-screenshot.jpeg)

LinkLite is a modern, responsive URL shortening website designed to simplify link sharing. Built with HTML, CSS, and JavaScript, it integrates with the TinyURL API to generate short, secure, and trackable URLs. The website features a professional UI with glassmorphism effects, GSAP animations, and a fully responsive design for seamless use across devices.

## Features
- **URL Shortening**: Convert long URLs into compact, shareable links using the TinyURL API.
- **Responsive Design**: Optimized for mobile, tablet, and desktop devices.
- **Interactive UI**: Glassmorphism navbar, animated hero section, and smooth hover effects.
- **Action Buttons**: Copy, refresh, and reset shortened URLs with user feedback.
- **Lazy Loading**: Images load on-demand to improve performance.
- **Accessibility**: ARIA attributes and semantic HTML for better usability.
- **Comprehensive Sections**: Includes About, Services, Features, Pricing, Team, FAQ, Reviews, Contact, and Footer.

## Technologies
- **HTML5**: Semantic structure for accessibility and SEO.
- **CSS3**: Bootstrap 5 for layout, custom styles with glassmorphism and animations.
- **JavaScript**: GSAP for animations, TinyURL API integration, and lazy loading.
- **External Libraries**:
  - Bootstrap 5.3.3 (CSS and JS)
  - GSAP 3.12.5 (Animations)
  - Animate.css 4.1.1 (Section transitions)
  - Bootstrap Icons 1.11.3 (Icons)

## Setup Instructions
To run this project locally or deploy it on your own GitHub Pages:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/muzamal478/LinkLite-URL-Shortener.git
   ```
2. **Navigate to the Project Folder**:
   ```bash
   cd LinkLite-URL-Shortener
   ```
3. **Open Locally**:
   - Open `index.html` in a browser to view the website locally.
   - Alternatively, use a local server (e.g., `live-server` via npm) for better testing:
     ```bash
     npm install -g live-server
     live-server
     ```
4. **Deploy to GitHub Pages** (see below for detailed instructions).

## Usage
1. **Shorten a URL**:
   - Enter a valid URL in the input field on the homepage.
   - Click the “Shorten” button to generate a short URL.
2. **Copy the Short URL**:
   - Click the “Copy Link” button to copy the shortened URL to your clipboard.
3. **Refresh or Reset**:
   - Use the “Refresh Link” button to generate a new short URL for the same input.
   - Use the “Reset” button to clear the input and output.
4. **Explore Sections**:
   - Navigate through the About, Services, Features, Pricing, Team, FAQ, Reviews, and Contact sections using the navbar.
